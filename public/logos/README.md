# Shop logos

`dia.svg`, `mercadona.svg`, `carrefour.png` and `alcampo.png` are the logos the shops publish on their own
websites, served here only to tell the shops apart. They are those companies'
trademarks, not part of this project's licence, and Cheap Groceries is not affiliated with
any of them.

- Dia: read from dia.es, `content-manager/image/Logos_footer_header/web_logo.svg`.
- Mercadona: downloaded from tienda.mercadona.es, `centered-logo-CZaib0q4.svg`.
- Carrefour and Alcampo: the shop logos as Findit serves them, `dx7csy7aghu7b.cloudfront.net/stores/<shop>/logo.png` (400 x 400 PNG).
